Selected Work

Projects

Production Ensemble ATS Recommendation Engine

An ensemble machine learning model that ranks and prioritizes recruiter job orders, deployed as a REST API integrated directly into the applicant tracking system. Includes automated feature engineering and scheduled retraining.

Finance P&L Automation Platform

An end-to-end pipeline that ingests General Ledger data using Informatica (IICS), SQL, and Python, then automates transformation, validation, and P&L reporting in Power BI. Built to handle changes in account and location hierarchies without breaking downstream reports.

SEC Filing Analysis Assistant

An Azure OpenAI–powered tool that analyzes SEC filings and aggregates data from multiple sources to generate client intelligence reports. Findings are delivered as automatically generated presentation decks for client-facing teams.

Labor Market Intelligence Platform

A platform that consolidates Lightcast, Dun & Bradstreet, SEC EDGAR, and U.S. Bureau of Labor Statistics APIs into a single product supporting labor market analysis. Findings are delivered through the same automated presentation tool used for client reporting.
